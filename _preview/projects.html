Gaussian Splatting Path Tracer

CompleteC++

3D Gaussian Splatting ray intersection integrated into a Monte Carlo path tracer.

CLICK FOR DETAILS

Implemented Features:

  • 3D Gaussian Splatting ray intersection: ellipsoid hit testing in Mahalanobis space following RaySplat (arXiv 2501.19196)
  • Gaussian BVH: dedicated axis-aligned BVH over Gaussian confidence ellipsoids for fast candidate collection
  • Alpha compositing: front-to-back depth sort by camera-space Z with deterministic tiebreaking; transmittance accumulation matching the 3DGS rasterizer convention
  • Spherical harmonics (degree 3): view-dependent color evaluation with SH coefficients loaded from PLY
  • PLY loader: binary PLY reader for 3DGS-trained scenes (63 floats per Gaussian: position, SH coefficients, opacity, scale, rotation quaternion)
